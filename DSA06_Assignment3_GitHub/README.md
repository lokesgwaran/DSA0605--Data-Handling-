# DSA06 – Data Handling and Visualization | Assignment 3

**CO3: Analyze data patterns, trends, and associations using visualization techniques**

This repository contains the Assignment 3 report, simulated teaching datasets, and visual output figures.

> **Data notice:** The datasets are simulated for this assignment and are not official Chennai air-quality or health records.

## Contents
- `datasets/`: three CSV datasets
- `report/`: report in DOCX and PDF formats
- `outputs/`: chart images

## Chart groups
- Part A: distributions, ECDF, Q-Q plots
- Part B: monthly distributions
- Part C: source shares and OPD-age visualization
- Part D: association plots, correlogram, PCA, lag and weekend plots
- Part E: moving averages, decomposition and forecast
- Part F: station point maps

These images are exploratory outputs; consult the report for methods, limitations, and interpretation.
